## ✨ Основные возможности

* **📊 Три режима отображения:** Быстрое переключение информации на кубе в один клик (Счетчик, Время, Скорость).
* **🔥 Динамическая система накала (Heat):** Чем быстрее вы печатаете, тем быстрее меняется цвет неоновой рамки виджета и тем больше визуальных эффектов (искр) генерируется внутри него.
* **🎨 Процедурные визуальные эффекты:**
  * **Эффект тряски (Shake):** Легкое дрожание текста при вводе символов.
  * **Эффект искр (Particles):** Вылетающие частицы из центра при нажатии клавиш, которые плавно угасают и удерживаются границами виджета.
  * **Эффект ряби (Ripples):** Круговые волны внутри куба при кликах мыши.
* **📥 Подробный лог сессий:** Автоматическое сохранение статистики каждой сессии (время старта/завершения, аптайм, количество нажатий клавиш и кликов мыши) в файл `stats_log.txt` в системной папке `AppData`.
* **💾 Автосохранение настроек:** Позиция куба на экране, язык интерфейса и состояние блокировки сохраняются между перезапусками.
* **🌐 Мультиязычный интерфейс:** Поддержка переключения между русским и английским языками на лету.
* **🔔 Интеграция с системным треем:** Сворачивание в трей средней кнопкой мыши (колесиком) или через контекстное меню.
* **🔲 Минималистичный дизайн:** Безрамочное полупрозрачное окно с эффектом «дыхания» рамки.

## ⚡ Режимы работы и отображения

Вы можете переключать информацию на экране кликом левой кнопки мыши по кубу:

| Режим | Что отображает | Особенности |
| :--- | :--- | :--- |
| **Счетчик (Counter)** | Общее число нажатий за сессию | Сопровождается эффектом тряски цифр и вылетом искр при вводе. |
| **Время (Time)** | Время запуска и общую длительность сессии | Формат отображения: `ЧЧ:ММ:СС`. |
| **Скорость (Speed)** | Скорость ввода в CPM и WPM | Рассчитывается в реальном времени на основе скользящего окна за 60 секунд. |

## ⚙️ Фильтрация ввода

По умолчанию программа работает в **режиме умного подсчета символов**:
* Игнорируются системные клавиши-модификаторы (`Ctrl`, `Alt`, `Win`).
* Игнорируются клавиши навигации и управления (`Enter`, `Backspace`, `Tab`, стрелки, `Page Up/Down` и др.).
* Пробел учитывается только в том случае, если он нажат без модификаторов.

В опции **"Учитывать клики мышью" (Count mouse clicks)**:
* Клики мыши учитываются в общем счетчике и создают эффект круговой ряби.
* В логе ведется раздельная статистика по клавишам и кликам.

## ⌨️ Управление виджетом

| Действие | Результат |
| :--- | :--- |
| **Клик ЛКМ** | Переключение режима отображения (Счетчик ➡️ Время ➡️ Скорость) |
| **Зажатие ЛКМ + перетаскивание** | Перемещение куба по экрану (если он не заблокирован) |
| **Клик СКМ (Колесико)** | Свернуть куб в системный трей / развернуть из трея |
| **Клик ПКМ** | Открытие контекстного меню настроек |

### Меню настроек (ПКМ):
* **Учитывать клики мышью** — включение подсчета кликов мыши.
* **Заблокировать / Разблокировать** — запрет на случайное перемещение виджета по экрану.
* **Приостановить / Продолжить подсчет** — временная остановка трекинга активности.
* **Сбросить счетчик** — обнуление текущей статистики и накала.
* **Скрыть в трей** — сворачивание виджета в область уведомлений.
* **Открыть лог статистики** — открытие файла `stats_log.txt` в стандартном текстовом редакторе.
* **Язык \ Language** — выбор языка интерфейса (Русский / English).
* **Выход** — сохранение лога сессии и закрытие приложения.

## 🚀 Варианты запуска

### Вариант 1. Запуск готового файла (Windows)
1. Скачайте `KeyboardCube.exe` из раздела [Releases](https://github.com/JorekTheOrc/Entered-Characters-Counting-Cube/releases) (или используйте готовый файл в корне проекта).
2. Запустите файл двойным кликом мыши.

---

### Вариант 2. Запуск Python-скрипта (Кроссплатформенный)

#### 1. Требования
Убедитесь, что у вас установлен Python версии **3.8 или новее**.

#### 2. Клонирование репозитория
```bash
git clone https://github.com/JorekTheOrc/Entered-Characters-Counting-Cube.git
cd Entered-Characters-Counting-Cube
```

#### 3. Установка зависимостей
```bash
py -m pip install PyQt5 pynput
```
*(или `python -m pip install PyQt5 pynput`)*

#### 4. Запуск приложения
```bash
py char_counter.py
```
*(или `python char_counter.py`)*

## 🛠️ Сборка собственного EXE-файла

Для сборки проекта в единый исполняемый `.exe` файл используется **PyInstaller**:

1. Установите PyInstaller:
   ```cmd
   py -m pip install pyinstaller
   ```
2. Запустите сборку:
   ```cmd
   py -m PyInstaller KeyboardCube.spec
   ```
   *(или без spec-файла: `py -m PyInstaller --noconsole --onefile --name "KeyboardCube" char_counter.py`)*

Скомпилированный файл появится в папке **`dist/KeyboardCube.exe`**.
